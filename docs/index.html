📊 czChart — Examples

Lightweight, data-driven chart library. Zero dependencies. Single <script> tag.

Line Chart LINE

Monthly revenue, cost & profit — smooth curves, 3 series

czChart.create('#chart-line', {
  type: 'line',
  data: [...],
  x: 'month',
  y: ['revenue', 'cost', 'profit'],
  series: { smooth: true, pointRadius: 3 }
});

Bar Chart BAR

Quarterly sales by region — grouped bars

czChart.create('#chart-bar', {
  type: 'bar',
  data: [...],
  x: 'quarter',
  y: ['north', 'south', 'east']
});

🆕 New Chart Types

Gauge Chart GAUGE NEW

Server CPU usage — semi-circle gauge with colored zones

czChart.create('#chart-gauge', {
  type: 'gauge',
  data: [{ label: 'CPU', value: 72 }],
  x: 'label', y: 'value',
  gauge: {
    min: 0, max: 100,
    zones: [
      { min: 0, max: 50, color: '#10b981' },
      { min: 50, max: 75, color: '#f59e0b' },
      { min: 75, max: 100, color: '#ef4444' }
    ]
  }
});
